## About

This site is my personal developer portfolio. It was originally built as the CDV05 portfolio project for my software development bootcamp at CodeSpace, where the brief was a clean, responsive, accessible site that showcases projects, skills and contact information.

## Features

- Single-page layout with smooth-scroll navigation between sections
- Dark theme with high-contrast text
- Custom typography using Montserrat for body text and Knewave for accents (via Google Fonts)
- Responsive layout intended to work across phone, tablet and desktop screens

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (current LTS recommended)
- npm (bundled with Node.js)
- [Git](https://git-scm.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/krugerjoshua/portfolioPage.git
cd portfolioPage

# Install dependencies
npm install

# Start the development server
npm run dev
```

Vite prints a local URL in the terminal (usually `http://localhost:5173`). Open it in your browser.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server with hot reload |
| `npm run build` | Create an optimised production build in `dist/` |
| `npm run preview` | Serve the production build locally to check it before deploying |

## Deployment

The site is deployed on [Netlify](https://www.netlify.com/) from the `main` branch.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Publish directory | `dist` |

## Contributing

This is a personal portfolio, so I am not looking for feature contributions. Bug reports and suggestions are welcome:

1. Open an [issue](https://github.com/krugerjoshua/portfolioPage/issues) describing the problem, including your browser and device.
2. For a small fix (typo, broken link, accessibility improvement), fork the repo, create a branch, and open a pull request against `main`.
